# ConvertBrio Content Calendar (8 weeks, 2 posts per week)

Goal: show ongoing, useful curation by publishing real, problem-focused guides.
Subham writes or reviews every post.

## Rules for every post

- **Publish with the real date.** Set `pubDate` to the actual publish day. Never backdate. When an old post is genuinely revised, set `updatedDate`; the site shows "Updated <date>" and sends `dateModified` in the Article schema.
- **Verify every number before publishing.** Upload limits (KB, pixels, MB) change. For any post that quotes a portal or form requirement, open the official page, note the date you checked, and write "check the current requirement on the official site" in the post. Do not copy a limit from memory or from this file.
- **Use real screenshots.** Each idea lists what to capture. Take them from the live tool with a real file, and write descriptive `alt` text.
- **Test the tool claim.** Run the exact file through the linked tool and state what really happened, including when the tool cannot reach the target. Don't promise outcomes the tool doesn't guarantee.
- **Do not duplicate** the 13 existing posts. Each idea below is a new angle; link to the existing post where it helps.
- Aim for 800-1,400 words, one clear problem, a numbered fix, a troubleshooting section, and a link to the tool.

Existing posts (do not repeat): page numbers on PDF, combine photos into a PDF, compress PDF to a specific size, compress PDF without losing quality, compress PowerPoint for email, HEIC won't open, image size guide, OCR scanned PDF to Word, PDF password restrictions, PDF to Word formatting loss, PNG vs WEBP vs AVIF, reduce photo size for online forms, when to remove a photo background.
