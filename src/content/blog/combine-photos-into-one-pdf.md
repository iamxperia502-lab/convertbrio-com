You've photographed a multi-page document: a signed contract, a set of receipts, a stack of handwritten notes, and now you have five separate JPGs cluttering your camera roll. Whoever you send them to has to open five attachments in the right order to make sense of them. A single PDF fixes that.

## Why a PDF instead of separate images

A PDF preserves page order automatically, opens the same way on every device without a photo viewer app, and reads as one document instead of a scattered set of attachments. It's also the format almost every form, portal, and email system expects when they ask for "a scanned copy" of something: uploading five JPGs instead of one PDF is a common way to have a submission rejected or flagged as incomplete.

## How to do it

1. **Photograph or export each page as an image first.** Keep the photos in the order you want them to appear: most tools combine them in the order they're uploaded or selected.
2. **Combine the images into a single PDF.** A [JPG to PDF tool](/tools/jpg-to-pdf) that accepts multiple files at once turns a folder of photos into one PDF, one page per image, in upload order.
3. **Double check the page order before sending.** If your file picker or camera roll doesn't sort the images the way you expect (alphabetically vs. by date taken, for instance), reorder or rename the files before uploading so page 1 actually ends up as page 1.

## If you already have separate PDFs instead of images

Sometimes the problem isn't photos: it's that you've already converted each page to its own single-page PDF and now need them as one document. That's a slightly different job: a [PDF merge tool](/tools/merge-pdf) combines multiple existing PDFs into one, in the order you arrange them, without needing to go back through images at all.

## A note on photo quality

Combining photos into a PDF doesn't fix bad photos: blurry, poorly lit, or crooked shots of a document will look exactly as blurry, poorly lit, or crooked inside the PDF. If the document needs to be legible (a contract, an ID, a receipt for reimbursement), it's worth taking a few extra seconds to make sure each photo is sharp and well-lit before combining them, since a five-page PDF you have to retake from scratch costs more time than getting it right the first pass.

If a page came out sideways, rotate it before combining: most people find it easier to fix orientation issues once the pages are already inside a single PDF, using a [PDF rotate tool](/tools/rotate-pdf), rather than trying to re-crop or re-orient the original photo.
